3. LEARNED GIT WORKFLOW
   - git status       — see what files are modified
   - git add <file>   — stage changes for commit
   - git commit -m "message" — save a checkpoint
   - git log --oneline — view commit history
   - git diff         — see unstaged changes
   - git diff --staged — see staged (but uncommitted) changes
   - git diff HEAD    — see ALL changes (staged + unstaged)
   - git show <hash>  — see details of a specific commit

   IMPORTANT: git log only shows COMMITTED changes.
   Changes must go through: edit → git add → git commit → appears in git log
